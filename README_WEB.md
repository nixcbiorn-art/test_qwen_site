# Weather Analytics Site + Browser Plugin

## 🚀 Быстрый старт

### 1. Запуск сервера
```bash
python run_all.py
```

Сервер запустится на `http://localhost:8000`

### 2. Открыть сайт
Перейдите в браузере на: **http://localhost:8000**

### 3. Установка браузерного плагина (Chrome/Edge)

1. Откройте браузер
2. Перейдите на `chrome://extensions/`
3. Включите **"Режим разработчика"** (переключатель в правом верхнем углу)
4. Нажмите кнопку **"Загрузить распакованное расширение"**
5. Выберите папку `extension` из проекта
6. Плагин установлен! Иконка появится в панели расширений

## 📁 Структура проекта

```
/workspace
├── run_all.py           # Скрипт запуска всего
├── server.py            # Веб-сервер (FastAPI)
├── templates/
│   └── index.html       # Главная страница сайта
└── extension/           # Браузерный плагин
    ├── manifest.json    # Манифест плагина
    ├── background.js    # Фоновый скрипт
    ├── popup.html       # Интерфейс попапа
    ├── popup.js         # Логика попапа
    └── content.js       # Контент-скрипт для страниц
```

## 🔌 API Эндпоинты

| Endpoint | Method | Описание |
|----------|--------|----------|
| `/` | GET | Главная страница с дашбордом |
| `/api/weather` | GET | Текущая погода по городам |
| `/api/analytics` | GET | Аналитика температур |
| `/api/scrape` | POST | Приём данных от плагина |

## 🛠 Функции плагина

- **Просмотр погоды** - быстрый доступ к данным о погоде
- **Аналитика** - средняя, мин и макс температура
- **Парсинг страниц** - ПКМ на странице → "Scrape this page"
- **Автообновление** - данные обновляются каждые 30 секунд

## 📊 Возможности сайта

- Реал-тайм дашборд с погодой по 4 городам
- Графики температуры (Plotly.js)
- Исторические данные
- Адаптивный дизайн

## 🔄 Как это работает

1. **Python сервер** собирает данные с Open-Meteo API каждые 30 секунд
2. **Сайт** отображает данные в реальном времени с автообновлением
3. **Плагин** через JavaScript обращается к локальному серверу за данными
4. **Парсинг** - плагин извлекает контент страницы и отправляет на сервер

## ⚠️ Важно

- Сервер должен быть запущен перед использованием плагина
- Плагин работает только при активном соединении с localhost:8000
- Для парсинга динамических сайтов может потребоваться дополнительная настройка CORS
